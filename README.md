
# Evaluating implicit biases in LLMs compared to humans: a word association network methodology

This repository contains the data and code relevant to the manuscript *Evaluating implicit biases in LLMs compared to humans: a word association network methodology*. The manuscript presents a novel methodology for evaluating implicit biases in LLMs compared to humans by measuring the strength of association between words within human-generated and LLM-generated word association networks. The metholodogy follows the same logic as the Implicit Association Test (IAT) for assessing biases in humans, but instead of using behavioral experiments for measuring the strength of association between words, it simulates semantic priming within associative network models of semantic memory built from free associations generated by both humans and LLMs. The bias evaluation methodology presented in the manuscript is applied to humans and three different LLMs (Mistral, Llama3, and Haiku) to evaluate biases related to gender, religion, ethnicity, sexual orientation, and political party. The contents of this repository can be used to reproduce the analyses conducted in the manuscript. They can also be used to extend the methodology to further investigations of biases in LLMs compared to humans.

-------
  
### Reproducing the analyses
The data used in the analyses come from the [SWOW](https://github.com/SimonDeDeyne/SWOWEN-2018) [1] and [LWOW](https://github.com/LLMWorldOfWords/LWOW) [2] datasets, which are comparable datasets of free association norms generated by humans and LLMs, respectively. Word association networks were built from the datasets following the procedure described in the paper [The “LLM World of Words” English free association norms generated by large language models](https://www.nature.com/articles/s41597-025-05156-9), by connecting cues to their responses, and then by cleaning and filtering the networks to eliminate unwanted nodes.

The analyses can be reproduced using the code and datasets in the *reproducibility* folder, however, due to licensing restrictions, the human word association network is not included in the repository. The human network (edgelist and igraph) can be generated following the detailed instructions on the [LWOW](https://github.com/LLMWorldOfWords/LWOW) github page, and should be saved in the *edgelists* and *igraphs* folders, respectively.

The *reproducibility* folder contains the following:
- *BiasEval_analyses.py* used first to generate lists of prime nodes and then to conduct the bias evaluation analyses using the activation level matrices
- *SpreadingActivation.r* used to implement the spreading activation processes on the networks using the lists of prime nodes and the igraphs
- The *data* folder contains the following:
    - The *graphs* folder, containing the word association networks in the form of edgelists (for loading the graphs) and igraphs (for the spreading activation processes)
    - The *primes_targets* folder, containing the lists of prime nodes and target nodes as .csv files
    - The *AL_matrices* folder, containing  the activation level matrices resulting from the spreading activation processes as .csv files
    - The *valence_emotions* folder, containing the valence data and emotions data that are used for the bias evaluation analyses, obtained from the [NRC-VAD Lexicon](https://saifmohammad.com/WebPages/nrc-vad.html) [3] research page and the [NRC Word-Emotion Association Lexicon](https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm) [3] research page, respectively.

### Extending the methodology
The purpose of the methodology is to provide a framework that can be extended to further investigations of biases. To investigate different types of biases using the same word association networks, it is sufficient to reproduce the analyses using different prime nodes and target nodes. Therefore, it is sufficient to update the .csv files containing primes and targets and then run the scripts *BiasEval_analyses.py* and *SpreadingActivation.r*. Additionally, new word association networks can be built using different LLMs, following the procedure described in the paper [The “LLM World of Words” English free association norms generated by large language models](https://www.nature.com/articles/s41597-025-05156-9).
